# 加權指數權值表

本機版台股加權指數前 100 大查詢工具。每日以昨收重算市值、權重與排行，並估算個股漲跌停對大盤的貢獻點數。

網站固定只監聽本機 `127.0.0.1`；請勿改成對外網路服務。

GitHub Pages 由 Actions 在每個交易日台北時間 18:20 左右重新抓取官方資料並發布；官方來源失敗或不足 100 檔時，該次部署會停止並保留上一版。

## 使用方式

直接雙擊 `啟動網站.cmd`。瀏覽器會自動開啟 `http://localhost:3000/`；關閉啟動視窗即可停止網站。

第一次抓取官方資料通常需要 5–20 秒，之後會保留 15 分鐘記憶體快取；也可按頁面上的「更新」強制重抓。

若需要用 CLI：

```powershell
$env:NODE_OPTIONS='--use-system-ca'
npm run dev
```

## 資料與計算口徑

- 成分股範圍、代碼與名稱：[TAIFEX 加權指數成分股暨市值比重](https://www.taifex.com.tw/cht/2/weightedPropertion)，每月底更新。
- 昨收、開盤競價基準價、漲跌停價、股本與加權指數昨收：[TWSE OpenAPI](https://openapi.twse.com.tw/)。
- 指數有效股數＝已發行普通股數－私募股數。
- 市值＝指數有效股數 × 昨收。
- 權重＝個股市值 ÷ 全體可計算成分股市值。
- 貢獻點數＝指數有效股數 ×（漲／跌停價－昨收）÷ 估算指數除數。

貢獻點數屬估算值。若遇除權息、減資等事件，今日開盤競價基準價可能不同於昨收；本版依指定口徑仍以昨收計算，因此「漲停貢獻」也可能呈負值，畫面會以 `＊` 標記。
